Development of an AI Coding Tutor Using Python and Gemini AI

Hello everyone,

For my project, I am developing an **AI Coding Tutor** to help students and beginners learn programming more easily with the support of artificial intelligence.

### 1. Frameworks and Technologies Used

In my project, I used **Python** as the programming language and **Streamlit** as the framework for building the web application interface. Streamlit allows me to create an interactive application without needing to write a lot of HTML, CSS, or JavaScript.

For the AI functionality, I used **Google Gemini AI** through the Google GenAI Python SDK. This allows users to ask programming questions and receive AI-generated explanations and suggestions.

I also use **Git and GitHub** to manage and store my project code. For deployment, I plan to use Streamlit Community Cloud so that users can access my application online.

Currently, I am connecting directly to the Gemini model rather than using an agent framework such as LangChain, LangGraph, or CrewAI.

### 2. Main Features of My Project

The main purpose of my AI Coding Tutor is to make programming easier for beginners. Some of the features I am developing include:

- **Ask AI:** Users can ask questions about programming and receive explanations.
- **Debug Code:** Users can submit code with errors and get help understanding and fixing them.
- **Run Code:** Users can run Python code and view the output.
- **Learn Programming:** The AI can explain coding concepts in simple language to help beginners understand them.

These features can help students learn at their own pace and practise programming more effectively.

### 3. Why I Chose Streamlit

I chose Streamlit because it is beginner-friendly, easy to learn, and works well with Python. It allows me to develop a web application quickly without having to build the entire frontend separately.

Streamlit also provides useful components, such as text input fields, buttons, sidebars, and code editors, which are helpful for building an interactive AI Coding Tutor.

### 4. Challenges Faced During Development

During the development process, I faced several challenges. One challenge was configuring the Gemini API key correctly so that my application could communicate with the AI model.

I also faced difficulties setting up Git, connecting my local project to GitHub, and preparing the application for deployment. Another challenge is handling errors when the AI service is temporarily unavailable.

I am learning to solve these problems by checking error messages, testing my code step by step, and improving the structure of my application.

### 5. Future Improvements Using AI Frameworks

In the future, I would like to explore frameworks such as **LangChain, LangGraph, and CrewAI** to improve my project.

LangChain could help me organise AI interactions and connect the model to additional tools. LangGraph could help me build a more structured workflow where the AI can manage different steps, such as analysing code, identifying errors, suggesting corrections, and explaining solutions.

CrewAI could be useful if I wanted to create multiple specialised AI agents. For example, one agent could explain programming concepts, another could identify coding errors, and another could suggest improvements to the code.

However, these frameworks are possible future additions to my project, and I have not integrated them into my current implementation.

### 6. Conclusion

In conclusion, developing an AI Coding Tutor has helped me understand how to combine Python, Streamlit, and Gemini AI to create a practical AI-powered application. It has also helped me improve my programming, debugging, and project management skills.

I believe that AI can support programming education by providing explanations and feedback when students encounter difficulties. In the future, I hope to improve my application by adding more advanced AI features and making it available online.
